# Off The Top Rope → AshLane Cast Intake

Shared worklist for the character generation pipeline. Owner generates some, Muse generates some, **owner approves every model before it ships**.

**Workflow:** Reference/image → Forge3D (or owner-side Tripo) → GLB → cleanup/normalize → retarget/rig → owner approval ("sucked/good") → into AshLane.

**Persona rule:** each character gets a based-on + persona decision. Some keep their wrestler persona, some get a new AshLane street persona. Never invent based-on relationships — owner confirms.
